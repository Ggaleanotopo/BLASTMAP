BLASTMAP WEB V0.4.1 - PARCHE MOVIL

CAMBIOS
1. Los botones rapidos del mapa en celular ahora son mas pequenos.
2. Se muestran solo en la vista MAPA.
3. Desaparecen automaticamente al entrar a Voladuras, Importar o Ajustes.
4. Se oculto el boton flotante grande redundante para evitar ocupar pantalla.

ACTUALIZACION RAPIDA EN GITHUB
1. Descarga y descomprime el ZIP de actualizacion.
2. En tu repositorio, abre public/styles.css e index.html.
3. Reemplaza esos archivos por los del ZIP.
4. Haz Commit changes.
5. Espera a que Netlify publique y vuelve a cargar el sitio.

Si prefieres, usa el proyecto completo V0.4.1 y crea un GitHub nuevo.
