BLASTMAP V0.4.2 - BOTONES Y CARPETA ÚNICA DXF

1. Crear o actualizar el repositorio GitHub con el ZIP COMPLETO, preservando public/ y .github/workflows/.
2. Conectar el repositorio a Netlify, con Publish directory: public.
3. El dueño de GitHub solo carga o borra DXF en public/voladuras/.
4. GitHub Actions genera public/voladuras-archivos.json automáticamente.
5. En GitHub, Settings > Actions > General > Workflow permissions: Read and write permissions (si la ejecución marca error de permisos).
6. Si un DXF usa un sistema distinto de MAGNA Central, cambiar su campo crs en public/voladuras-archivos.json (magna_nacional, magna_oeste, magna_este, etc.). El flujo conserva los CRS existentes al regenerar.
7. Esperar que termine la acción y el despliegue de Netlify. Los visitantes recargan el visor.
8. En el celular, cuatro iconos en Mapa: GPS, ubicación, medir y centrar. Solo se ven en Mapa.

PARA BORRAR UN ARCHIVO DXF EN GITHUB:
- Entra a tu repositorio > public > voladuras > abre el archivo DXF.
- En el menú de tres puntos (...), elige Delete file (Eliminar archivo), confirma el commit.
- Si GitHub no permite borrar el archivo desde esa pantalla, usa la interfaz de edición del repositorio o carga los cambios mediante otra herramienta autorizada.
- El listado se actualiza automáticamente al completarse GitHub Actions.
- IMPORTANTE: borrar un archivo de GitHub no borra sus copias locales ya importadas en los teléfonos.
