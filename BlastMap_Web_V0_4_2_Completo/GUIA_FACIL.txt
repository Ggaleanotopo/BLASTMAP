BLASTMAP WEB V0.3 — SIN PROGRAMAS NI CONTRASEÑA EXTRA

A) PRIMERA VEZ
1. Extraer el ZIP con Windows (sin instalar).
2. GitHub -> tu repositorio blastmap-web -> Add file -> Upload files.
3. Subir la carpeta public y el archivo netlify.toml a la RAÍZ. Commit changes.
4. Netlify -> Add new project -> Import an existing project -> GitHub.
5. Elegir blastmap-web. Publish directory: public. Publish.
6. Abrir el link de Netlify desde cualquier celular.

B) PARA PUBLICAR VOLADURAS NUEVAS
1. Abrir BlastMap en el navegador.
2. Importar DXF/KML/KMZ/GeoJSON (elegir el sistema del DXF antes de abrirlo).
3. Abrir MASTER, marcar archivos y pulsar Descargar archivo de publicación.
4. GitHub -> repositorio -> carpeta public -> Add file -> Upload files.
5. Subir/reemplazar voladuras-oficiales.json y pulsar Commit changes.
6. Netlify publica automáticamente (si está conectado a GitHub).
7. Los operadores abren el enlace: verán las áreas oficiales actualizadas.

C) PARA LOS OPERADORES
1. Solo abrir el enlace de Netlify en el celular.
2. Activar GPS cuando sea necesario.
3. Opcional: importar DXF/KML/KMZ propios y cambiar las coordenadas visibles.
4. Sus áreas personales NO reemplazan las oficiales.

NO NODE.JS. NO COMANDOS. NO CONTRASEÑA NUEVA DEL MASTER.
NOTA: GitHub sí requiere la cuenta autorizada del MASTER para cambiar archivos.
NO usar como sistema de seguridad de voladuras: GPS puede ser impreciso o el mapa desactualizado.

ACTUALIZACIÓN CARTOGRÁFICA: para conservar el inventario oficial existente, cambia solo geo.js, index.html, app.js y sw.js dentro de public/. No subas un voladuras-oficiales.json vacío.
