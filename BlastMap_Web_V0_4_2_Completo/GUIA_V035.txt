BLASTMAP WEB V0.3.5 - ORTOFOTO JPG/JGW/PRJ Y GOOGLE SATELITE

PARA ACTUALIZAR SIN INSTALAR PROGRAMAS
1. Descarga BlastMap_V0_3_5_Parche_Google_PRJ.zip y extráelo.
2. Abre el repositorio GitHub y entra a public.
3. Sustituye public/index.html, public/app.js, public/styles.css, public/sw.js.
4. Confirma con Commit changes; Netlify vuelve a publicar.
5. Recarga la página en el iPhone. Si ves versión anterior, cierra pestaña/reabre o elimina datos del sitio.
NO sustituir public/voladuras-oficiales.json.

ORTOFOTO
1. En Importar abre 'MAPA DE FONDO · ORTOFOTO'.
2. Pulsa selección de archivos. Selecciona JPG, JGW y PRJ (si existe) juntos.
3. Elige sistema de coordenadas de la imagen y pulsa Cargar ortofoto.
4. El world file JGW define escala, rotación y posición; el PRJ describe el sistema espacial.
5. Si PRJ señala Origen Nacional o Central y no coincide con el selector, se avisa.
ATENCIÓN: El reconocedor PRJ actualmente verifica expresamente Central y Origen Nacional; los demás WKT deben validarse manualmente. La imagen JPG no se guarda como capa oficial.

GOOGLE SATELITE
1. En https://console.cloud.google.com/ crea o selecciona un proyecto.
2. Configura facturación según las condiciones vigentes de Google Maps Platform.
3. Habilita Maps JavaScript API.
4. Crea una API key con restricción de sitio web (HTTP referrers), por ejemplo https://TU-SITIO.netlify.app/*.
5. Abre BlastMap > Importar > Fondo de Google Maps.
6. Pega la API key en el campo correspondiente y pulsa Activar Google Satélite.
7. Las voladuras se superponen como polígonos sobre la imagen satelital de Google.
Google requiere Internet y una clave válida. La clave se introduce solo durante la sesión; no se sube a GitHub.
ADVERTENCIA: La API key viaja al navegador y es visible técnicamente. Restringe el dominio y controla cuotas y presupuestos en Google Cloud.

LIMITACIONES
- El modo Google tiene navegación y controles cartográficos propios; medición horizontal por dos clics y selección de voladuras están integradas, pero algunas herramientas del plano local pueden tener comportamiento diferente.
- No se admite descarga offline de Google Satélite.
- GPS, georreferenciación, deformaciones de ortofoto y superposición deben validarse en campo antes de uso operativo.
