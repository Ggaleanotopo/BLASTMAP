BLASTMAP WEB 0.3.4 - MAPA DE FONDO

1. DESCOMPRIME el ZIP de actualizacion.
2. En GitHub, entra a la carpeta public del repositorio.
3. Reemplaza app.js, index.html y sw.js. Pulsa Commit changes.
4. Netlify publicara los cambios. Actualiza la pagina del celular.
5. En BlastMap abre Importar.
6. En la seccion MAPA DE FONDO selecciona el sistema en que esta georreferenciada la ortofoto.
7. Pulsa Elegir archivos y selecciona el JPG y el JGW juntos.
8. Pulsa Cargar ortofoto; ajusta transparencia o quita el fondo cuando quieras.

IMPORTANTE
- El JGW solo tiene seis valores de ubicacion/escala/rotacion, NO informa el sistema de coordenadas. Debes seleccionarlo correctamente.
- Para JPG/JGW de gran tamano conviene reducir resolucion o generar teselas; en esta version se limita el archivo a 80 MB.
- La ortofoto importada es PERSONAL y EN ESTA SESION; no se comparte automaticamente con otros operadores.
- GOOGLE MAPS no esta incorporado en esta entrega. Su integracion exige una API oficial y permisos/licencia; los mapas de Google no pueden descargarse arbitrariamente para uso offline.
- El visor conserva las areas oficiales; no subas ni reemplaces voladuras-oficiales.json.
- Las ortofotos no cambian las coordenadas reales de las voladuras.
