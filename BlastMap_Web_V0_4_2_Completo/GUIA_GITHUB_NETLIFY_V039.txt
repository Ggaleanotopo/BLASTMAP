BLASTMAP WEB V0.3.9 - INSTALACION SIN PROGRAMAS

1. Descarga y descomprime el archivo ZIP completo.
2. En github.com/new crea un repositorio privado nuevo (ej. blastmap-web).
3. Usa Add file > Upload files para subir el CONTENIDO de la carpeta descomprimida, no el ZIP.
4. En la raiz del repositorio deben verse public y netlify.toml.
5. En Netlify: Add new project > Import existing project > GitHub. Elige tu repositorio.
6. Publish directory: public. Build command: vacio. Publica.

ACTUALIZAR DXF OFICIALES SIN MASTER
1. En GitHub, abre public/voladuras.
2. Usa Add file > Upload files y sube los DXF que deseas mostrar.
3. En GitHub abre public/voladuras-archivos.json y pulsa el lapiz Edit.
4. Coloca la lista de archivos y el sistema de coordenadas de CADA DXF, por ejemplo:
{
 "version":"2026-11-02-02",
 "publishedAt":"2026-11-02T08:00:00-05:00",
 "files":[
  {"file":"VOLADURAS-B12-N-130.dxf","crs":"magna_central"},
  {"file":"VOLADURA-B13-N-30.dxf","crs":"magna_central"}
 ]
}
5. Cambia version cada vez que edites, agregues o elimines DXF. Pulsa Commit changes.
6. Netlify publicara. Los telefonos consultan el listado y cargan las areas.
7. Para quitar un DXF de la visualizacion, borra su linea en files y cambia version.

Los sistemas crs validos son magna_central, magna_nacional, magna_oeste, magna_este,
magna_oeste_oeste, magna_este_este y wgs84.
IMPORTANTE: no supongas el sistema de coordenadas de un DXF. Verifica contra puntos de control.

EN EL CELULAR
- Activar GPS: inicia/detiene el seguimiento.
- Mi ubicacion: centra el mapa en la posicion GPS recibida.
- Medir: toca dos puntos del mapa para conocer la distancia horizontal.
- Centrar areas: ajusta los limites de los poligonos visibles, sin necesidad de GPS ni Internet.
- Voladuras: marca/desmarca archivos y capas.

SIN INTERNET
Si la pagina ya se abrio desde HTTPS y se guardaron datos oficiales en el dispositivo,
se mostrara la ultima copia oficial guardada. El GPS puede funcionar offline si el dispositivo
ofrece posicion. Google Satelite requiere conexion. Sin una instalacion previa del sitio,
no se garantiza acceso offline en todos los navegadores.

ADVERTENCIA
BlastMap es un visor orientativo; no sustituye los protocolos de seguridad de voladura.
